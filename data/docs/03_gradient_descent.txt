Gradient Descent is a first-order iterative optimization algorithm used to find local minima of a differentiable loss function. In training machine learning models, model parameters (weights and biases) are iteratively updated in the opposite direction of the gradient of the loss function with respect to the parameters. Variants include Stochastic Gradient Descent (SGD), Batch Gradient Descent, and Mini-batch Gradient Descent. Popular adaptive optimizers like Adam and RMSprop adjust learning rates dynamically per parameter.
